# Full dependency audit for the design/structural/damage/loss pipeline
# (Codes/designModule, Codes/structuralModule, Codes/schema, Codes/damageModule,
# Codes/lossModule) plus the notebook/plotting stack used to run and inspect it.
#
# NOT covered here: ATC-138's functional-recovery methodology
# (Codes/lossModule/Loss_ATC138) needs a licensed MATLAB install plus the
# matching MATLAB Engine API for Python (`matlabengine` on PyPI, version-pinned
# to your MATLAB release -- see MathWorks' own install instructions); there's
# no plain pip path for MATLAB itself.

# --- Design / structural / schema ---
numpy
pandas>=2.2  # pandas <2.2 is ABI-incompatible with numpy>=2.0 and fails to import
pydantic>=2
pyyaml
requests  # Codes/designModule/check_user_inputs.py

# --- Structural module: OpenSeesPy analyses (eigen/pushover/dynamic) ---
# Needed for `run_designModule.py --engine openseespy`, the openseespy_* CLIs,
# and the openseespy driver notebook. The default `--engine tcl` path needs
# none of this -- it only writes .tcl files.
# openseespy<3.8.0.0's macOS wheel (openseespymac) was mistagged `py3-none-any`
# but actually bundled x86_64-only binaries -- it silently failed to import on
# Apple Silicon. 3.8.0.0 ships a real native arm64 wheel (openseespymac
# `macosx_13_0_arm64`) and requires Python>=3.10.
openseespy>=3.8.0.0

# --- Plotting / notebooks (damage-module plotting, both driver notebooks) ---
matplotlib
jupyter
ipykernel
nbconvert  # only needed to execute notebooks headlessly (e.g. `jupyter nbconvert --execute`)

# --- Damage module (EDP extraction, collapse/demolition fragility fitting) ---
scipy
statsmodels
sympy
seaborn
numdifftools

# --- Loss module: Pelicun (FEMA P-58 damage/loss assessment) ---
# Real installable package (https://github.com/NHERI-SimCenter/pelicun), replacing
# a 45MB vendored/forked copy of pelicun 3.1 that existed only because that old
# version's DL_calculation.run_pelicun() didn't take explicit demand-file/output-path
# arguments (needed to call it once per hazard level in a loop) -- current pelicun
# already does. simcenter-dlml (the damage/loss model-library data) installs
# automatically as pelicun's own dependency; no separate download step.
pelicun>=3.10,<4.0

# --- Input-authoring GUI (Codes/gui/, `streamlit run Codes/gui/app.py`) ---
# Local-only -- no hosting required. streamlit's own dependency resolution can
# pull in an old altair release that's incompatible with it on some Python
# versions; if `streamlit run` fails on import with an altair error, upgrade
# both (`pip install --upgrade streamlit altair`). Needs Python>=3.10 for the
# same reason openseespy does (see above) -- avoid 3.9.7 specifically,
# streamlit itself refuses to install on that exact patch version.
streamlit
plotly
